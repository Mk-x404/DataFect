# Compulsory Agent Usage Rules

This project enforces the strict utilization of specialized AI agents from the `agency-agents` collection to maintain high standards of code quality, architecture, and design.

When performing tasks in this repository, you **MUST** follow these rules:

1. **Role Identification**: Before starting any non-trivial implementation or review, identify the appropriate specialized agent skill (e.g., `agency-frontend-developer`, `agency-backend-architect`, `agency-code-reviewer`, `agency-product-manager`) that fits the task.
2. **Skill Activation**: You must load and adhere to the guidelines of the chosen specialized agent by reading and following its skill instructions. 
3. **No Generic Responses**: Avoid providing generic, general-purpose advice. All technical decisions must be grounded in the perspective of the specialized agent persona.
4. **Architectural Decisions**: For backend changes, always consult the principles of `agency-backend-architect`. For frontend changes, consult `agency-frontend-developer`.
5. **Code Review**: When reviewing code, adopt the strict standards of `agency-code-reviewer`.

> [!IMPORTANT]
> The utilization of these specialized agent skills is **compulsory**. Failure to adopt the appropriate persona before executing complex tasks is a violation of project rules.
